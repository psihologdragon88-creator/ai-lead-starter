# Пространство ИИ-лидера

Стартовое пространство для этапа 1. Здесь правила, справочник по Git
и несколько готовых инструментов. Отсюда вы начинаете.

## Владелец и рутина

**Антон Антон** · рутина: **разрезание кейса для переговорных поединков**.

Рутина: взять полный кейс (инструкция менеджеру + клиенту), разрезать
на три части — «полный / менеджер / клиент» — в Word и PDF, проверив
логику (стороны не должны противоречить друг другу) и грамотность.
Инструмент в папке `Проверка кейсов` — загружаешь полный .docx,
получаешь 6 файлов.

## Как забрать себе

Два способа, оба рабочие.

**Форк** — если хотите свою копию на GitHub, связанную с оригиналом.
Кнопка **Fork** справа вверху на этой странице. Потом у себя:

```
git clone https://github.com/ВАШ-ЛОГИН/ai-lead-starter.git
```

**Скачать архивом** — если проще без GitHub. Зелёная кнопка **Code** →
**Download ZIP** → распаковать.

**Или склонировать напрямую:**

```
git clone https://github.com/rttrener-gif/ai-lead-starter.git
```

## С чего начать

1. Забрать пространство себе — любым способом выше
2. Открыть папку в редакторе: `File → Open Folder`
3. Открыть `README.html` двойным кликом и прочитать — там подробное описание.
   На GitHub этот файл показывается как исходный код, его нужно открывать
   у себя на компьютере
4. Вписать себя в верхний блок `AGENTS.md` и описать свою рутину в `README.md`
5. `git add .` → `git commit -m "описал свою рутину"` → `git push`

## Что где

| | |
|---|---|
| `AGENTS.md` | Правила, которые агент читает всегда. Он же — образец для вашего |
| `git-spravochnik.html` | 12 команд Git с объяснениями и кнопками в Cursor |
| `skills/` | Готовые инструменты + заготовка `_shablon-SKILL.md` для урока 2 |
| `.gitignore` | Что никогда не уходит в репозиторий |

Всё остальное — папки навыка, `runs/` с журналом прогонов — вы соберёте
сами на уроке 2. Это часть занятия, а не то, что выдаётся готовым.

## Главное правило

Если файл нельзя отправить внешнему подрядчику по почте — он не идёт
ни в репозиторий, ни в чат с ИИ, ни на публикацию.

Сомневаетесь — скажите агенту «обезличь этот файл».

# Ассеты дизайн-системы

Здесь фирменные шрифты и логотипы организации:

```
assets/
├── fonts/   ← Rostelecom Basis Light / Medium / Bold (скопированы из рабочей
│             папки «Проверка кейсов» ШЭП)
└── logos/   ← пока пусто, логотипы нужно взять у дизайнеров
```

## Почему папка пустая

**Фирменные шрифты и логотипы — ресурсы организации.** Они не выкладываются
в открытый доступ, поэтому в этом репозитории их нет и не будет.

Возьмите их у своих дизайнеров и положите сюда сами. После этого пропишите
пути к нужным файлам в блоке §0 файла `../SKILL.md`.

## Без ассетов скилл тоже работает

Он продолжает быть справочником: даёт сетку, размеры, типы слайдов, порядок
сборки и запреты. Не сможет только вставить настоящий логотип и фирменный
шрифт — вместо шрифта используйте Arial.

## Какой формат когда нужен

| Формат | Куда |
|---|---|
| `.otf` | PPTX, DOCX, PDF, установка в систему |
| `.woff`, `.woff2` | только веб, в Office не работают |
| `.svg` | логотипы везде, где поддерживается |
| `.png` | логотип там, где SVG не открывается — мессенджеры, превью |

## Установка шрифта в систему

- **macOS:** открыть `.otf` → «Установить шрифт».
- **Windows:** правой кнопкой по `.otf` → «Установить для всех пользователей».

В PowerPoint дополнительно включите «Файл → Параметры → Сохранение →
Внедрить шрифты в файл», иначе на чужом компьютере макет поедет.
